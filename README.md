# 🌈 SYNERGIE Multitool V6.1

**Un multitool Python en français, conçu pour regrouper des outils pratiques dans une interface terminal cyber et colorée.**

SYNERGIE propose une interface interactive avec animation de démarrage, menus numérotés et aide intégrée pour comprendre les différentes commandes.

## ✨ Fonctionnalités

- 🔎 **OSINT public** — recherches de pseudos, outils de recherche web et consultation de sources publiques.
- 🌐 **Réseau** — outils DNS, informations IP et diagnostics réseau.
- 🛡️ **Sécurité locale** — utilitaires et contrôles sur les fichiers et le système.
- 🤖 **Discord** — ressources, outils pratiques et assistant de génération d'un projet de bot.
- 📱 **Téléphonie** — validation et normalisation des numéros, indicatifs et utilitaires.
- 💻 **Système** — informations système et outils divers.
- 📘 **Aide intégrée** — consultez une commande par son numéro pour comprendre son rôle.

## 🪟 Windows

Le projet inclut une configuration de compilation permettant de générer `SYNERGIE.exe` sous Windows, ainsi qu'un workflow GitHub Actions prévu pour automatiser cette compilation.

## 🚀 Installation

Consultez le README pour installer les dépendances, lancer le programme Python ou générer l'exécutable Windows.

## 🔐 Utilisation responsable

Utilisez les fonctions OSINT uniquement sur des informations publiques et respectez la vie privée, les lois applicables et les conditions des plateformes. Les diagnostics doivent être effectués uniquement sur des systèmes que vous possédez ou êtes autorisé à tester.
